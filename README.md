# analytics-portfolio
Analytics portfolio, SQL, Excel, and dashboard projects that show how I turn operational data into reporting leaders trust.
## Projects

1. Peak Hours SQL Analysis. Live in [peak-hours-sql](peak-hours-sql). Hourly sales analysis that finds peak hours and turns them into a staffing recommendation.
2. Commission Payout Model. Live in [commission-payout-model](commission-payout-model). Payout tiers, reconciled totals, and mismatch flags in SQL and Excel.
3. Data Quality Audit. Live in [data-quality-audit](data-quality-audit). SQL checks that catch nulls, duplicates, and mismatches between tables.
4. Dashboard Sample. Live in [dashboard-sample](dashboard-sample). One public dashboard that answers one business question with a clear takeaway.
5. Process Improvement Case Study. Coming soon. A rollout story about training, adoption, and consolidating reporting onto Tableau.
6. Data Quality Agent. In progress, Day 1 sample live in [data-quality-agent](data-quality-agent). A first AI agent that flags duplicate, missing, and invalid sales records for human review.

## How to read this repo

Each project lives in its own folder with a README, the artifact, and a sample of the output. No real employer or client data is used anywhere.
